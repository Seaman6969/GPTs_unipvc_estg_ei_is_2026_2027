GPT Suite

One-line installers for LocalGPT, PrivateGPT, and WebGPT. Linux x86_64, no dependencies beyond curl.

LocalGPT

offline

Fully offline assistant. Runs entirely on your machine — no API keys, no network calls.

curl -fsSL https://raw.githubusercontent.com/Seaman6969/LocalGPT_unipvc_estg_ei_is_2026_2027/main/install.sh | bash
Advanced
Pin a Git tag, e.g. v0.1.0. Leave as latest for the newest release.

Requires: Linux x86_64 · glibc ≥ 2.31 · curl
